# AI Blog Topic & Outline Generator

An AI-powered blog topic and outline generator built using Streamlit and Groq LLM API.

## Features

- AI-generated blog titles
- SEO keyword generation
- Blog outline creation
- Writing tone customization
- PDF export
- Modern Streamlit UI

## Technologies Used

- Python
- Streamlit
- Groq API
- Llama 3.1
- Pydantic
- FPDF

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
